## Conversor de Medidas – Pés ↔ Metros (Java)

📖 Sobre o Projeto

Este projeto é um programa simples em Java que realiza a conversão de unidades de medida entre pés (feet) e metros (meters).

A ideia do programa surgiu após ouvir um podcast onde os participantes estavam discutindo a altitude de um avião em pés e houve confusão sobre a conversão para quilômetros/metros.
Então surgiu a ideia de criar um pequeno programa para fazer essa conversão corretamente.

🚀 

## Funcionalidades

O programa permite:

Converter pés para metros
Converter metros para pés
Entrada de dados pelo teclado
Saída formatada com duas casas decimais

## 🖥️ Como o programa funciona

Ao executar o programa, o usuário escolhe:

1 → Converter de pés para metros <br>
2 → Converter de metros para pés <br>

Depois basta digitar o valor que deseja converter e o programa mostrará o resultado.


## 🧮 Fórmulas utilizadas

1 pé = 0.3048 metros <br>
metros → pés = metros / 0.3048 <br>
pés → metros = pés × 0.3048 <br>
